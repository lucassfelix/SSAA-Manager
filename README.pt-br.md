
# Demonstração de um framework paramétrico para sistemas de gestão web

[![English](https://img.shields.io/badge/English-EN-brightgreen)](README.md)
[![Português (BR)](https://img.shields.io/badge/Português-PT--BR-blue)](README.pt-br.md)
[![Español](https://img.shields.io/badge/Español-ES-red)](README.es.md)

Este projeto está sendo desenvolvido com o **NeoFront**, um framework totalmente paramétrico que utiliza metadados para a construção de sistemas de gestão web. Em vez de codificar manualmente cada página, formulário ou tabela, toda a aplicação é definida por meio de configurações declarativas, que geram a interface, o comportamento e o tratamento de dados dinamicamente. A aplicação inclui navegação, localização, temas, filtros e operações CRUD que são produzidas automaticamente, em tempo real, a partir de metadados estruturados.

## Stack de desenvolvimento

Desenvolvido com React, Mantine UI e componentes do Mantine Data Grid. Também utiliza o React Router para navegação e o Vite como ferramenta de build.

## Sobre esta demonstração

A aplicação de exemplo inclui um menu com listas, filtragem e ordenação, indicadores de status, avatares e espaços reservados para fluxos transacionais. Também demonstra preferências configuráveis, como modo claro/escuro, densidade da lista e escala global da interface.

## Status do projeto

Este framework está em pleno desenvolvimento. Novos recursos e aprimoramentos estão sendo adicionados continuamente conforme a arquitetura evolui. O objetivo é criar uma base totalmente genérica para o desenvolvimento rápido de aplicações baseadas em metadados.
