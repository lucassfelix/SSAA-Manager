This project is being developed with **NeoFront**, a fully parametric, metadata-driven framework for building web management systems. Instead of manually coding each page, form, or table, the entire application is defined through declarative configuration, which drives UI generation, behavior, and data handling dynamically. The application includes navigation, localization, theming, filters, and CRUD operations that are automatically produced in real time from structured metadata.

## Key features

- Developed with React, Mantine UI, and Mantine Data Grid.
- **Declarative architecture**: menus, pages, fields, and actions are fully defined in metadata.
- **Dynamic UI generation**: layout and behavior are immediately rendered based on definitions.
- **Theme support**: complete theme customization including user-switchable light and dark mode.
- **Multi-language support**: includes internationalization support via the included code builder.
- **Consistent UX**: a single set of definitions ensures full consistency with uniform navigation, form controls, and tables.
- **Flexible integration**: easily connects to API gateways, microservices, BFF layers, or mock data.
- **Scalable design**: with AI-assisted generation, new modules, menus, and screens can be added on the fly without modifying core code.

## About this demo

The sample app includes a menu with lists, filtering and sorting, status indicators, avatars, and placeholders for transactional flows. It also demonstrates configurable preferences such as light/dark mode, list density, and global interface scaling.

## Project status

This framework is an active work in progress. New features and refinements are being added continuously as the architecture evolves. The goal is to create a fully generic foundation for rapid, metadata-driven application development.
