
# Demostración de un framework paramétrico para sistemas de gestión web

[![English](https://img.shields.io/badge/English-EN-brightgreen)](README.md)
[![Português (BR)](https://img.shields.io/badge/Português-PT--BR-blue)](README.pt-br.md)
[![Español](https://img.shields.io/badge/Español-ES-red)](README.es.md)

Este proyecto se está desarrollando con **NeoFront**, un framework totalmente paramétrico que utiliza metadatos para la construcción de sistemas de gestión web. En lugar de codificar manualmente cada página, formulario o tabla, toda la aplicación se define mediante configuraciones declarativas, que generan la interfaz, el comportamiento y el manejo de datos de forma dinámica. La aplicación incluye navegación, localización, temas, filtros y operaciones CRUD que se producen automáticamente, en tiempo real, a partir de metadatos estructurados.

## Estado del proyecto

Este framework está en pleno desarrollo. Nuevas funciones y mejoras se están agregando continuamente a medida que evoluciona la arquitectura. El objetivo es crear una base completamente genérica para el desarrollo rápido de aplicaciones basadas en metadatos.
